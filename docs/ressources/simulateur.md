# 📘 Utiliser les TP du simulateur

Le **simulateur réseau** est un fichier unique, qui fonctionne **sans Internet** dans un navigateur.

[🖥️ **Ouvrir le simulateur**](../simulateur/simulateur-reseau.html)

## Ouvrir un TP

1. Télécharge le fichier `.json` du TP (dans le dossier `tp/` de la séance : clic droit → *Enregistrer le lien sous*).
2. Dans le simulateur, clique sur **Ouvrir** et choisis le fichier.
3. Le schéma du TP s'affiche : équipements, câbles, adresses déjà prévues.

## Utiliser les équipements

| Je veux… | Je fais… |
|---|---|
| Ouvrir le terminal ou la configuration | **Double-clic** sur l'équipement |
| Ajouter un équipement | Glisser depuis la palette de gauche |
| Brancher / débrancher | Bouton **Câble** / sélectionner le câble puis **Supprimer** |
| Regarder les trames | Clic droit sur un câble → **Analyser cette liaison** |
| Recommencer à zéro | **RAZ réseau** (efface ce que les équipements ont appris) |
| Faire passer le temps | **+1 min** |

## Enregistrer mon travail

Clique sur **Enregistrer** : un fichier `.json` est créé. Ouvre-le plus tard avec **Ouvrir**. **Nomme-le** `TP-S11-nom.json` pour le retrouver.

> [!TIP]
> Le simulateur n'envoie rien sur Internet. Tout reste dans ton navigateur.
