## Plan d'adressage à respecter

| Équipement | VLAN | Adresse | Passerelle | Port du switch |
|---|---|---|---|---|
| `PC-1`, `PC-2` | 10 POSTES | DHCP (`.50` et +) | 192.168.10.1 | Fa0/1, Fa0/2 |
| `IMP` (imprimante) | 40 OBJETS | 192.168.40.20/24 | 192.168.40.1 | Fa0/3 |
| `NAS` | 40 OBJETS | 192.168.40.30/24 | 192.168.40.1 | Fa0/4 |
| Switch cœur `CORE` | – | `.10.1` et `.40.1` | – | – |

> [!NOTE]
> **Qui distribue les adresses ?** Il n'y a **pas de serveur DHCP** sur le schéma : c'est le **switch cœur `CORE`** qui joue ce rôle. C'est un switch de **niveau 3** : il **route** entre les VLAN **et** peut **distribuer des adresses** (service DHCP). C'est fréquent dans une petite structure, où l'on évite d'ajouter un serveur de plus. Le NAS et l'imprimante n'en ont pas besoin : leurs adresses sont **fixes**.

## Partie A – Câbler (≈ 15 min)

Relie les 4 équipements à `CORE` (`PC-1` → Fa0/1, `PC-2` → Fa0/2, `IMP` → Fa0/3, `NAS` → Fa0/4).

✅ **Point de contrôle :** tous les liens sont verts.

## Partie B – VLAN et routage (≈ 45 min)

Sur `CORE` (mode `enable`, puis `configure terminal`) :

1. **Routage :** `ip routing`.
2. **VLAN :** `vlan 10` + `name POSTES` ; `vlan 40` + `name OBJETS`.
3. **Ports d'accès :** `Fa0/1`–`Fa0/2` dans le VLAN 10 ; `Fa0/3`–`Fa0/4` dans le VLAN 40 (`switchport mode access`, `switchport access vlan …`).
4. **Interfaces VLAN** (la passerelle de chaque réseau) : `interface vlan 10` → `ip address 192.168.10.1 255.255.255.0` → `no shutdown` ; idem `vlan 40` avec `192.168.40.1`.
5. **Service DHCP pour les postes :**

```text
ip dhcp excluded-address 192.168.10.1 192.168.10.49
ip dhcp pool POSTES
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
```

   - `excluded-address` : les adresses `.1` à `.49` **ne seront jamais distribuées** (on les garde pour la passerelle et les équipements à adresse fixe) ;
   - `ip dhcp pool POSTES` : crée la plage d'adresses (le *pool*) ;
   - `network` : le réseau à distribuer ; `default-router` : la **passerelle** donnée aux postes.
6. `write memory`.

> [!TIP]
> Pour vérifier le DHCP : sur `CORE`, `show ip dhcp binding` (adresses distribuées) ; sur le poste, `ipconfig`.

✅ **Points de contrôle :** `show vlan brief` ; `show ip interface brief` (`Vlan10`, `Vlan40` en `up`).
