### B2. Les règles

- **Une panne à la fois** ; chaque correction est **vérifiée** avant la suivante.
- Après toute correction de VLAN ou de relais, pense à `ipconfig /renew` sur le poste concerné.
- Rends tous les tests du cahier de recette **verts** à la fin.

<details markdown="1"><summary>💡 Aide (si tu bloques depuis plus de 15 minutes)</summary>

- Panne « pas d'adresse » : vérifie la **diffusion** : `show running-config` sur `R1`, interface côté Direction.
- Panne « poste de l'Atelier ressemble à un invité » : `show vlan brief` sur `SW1`, **où est son port** ?
- Panne « site par adresse mais pas par nom » : le nom a besoin du **DNS** ; la règle du **DNS** est-elle dans l'ACL ? `show access-lists` : lis les **numéros** d'ordre.

</details>

<details markdown="1"><summary>💡 Aide 2 : ajouter une règle à une ACL existante</summary>

Une règle ajoutée **à la fin** arrive **après** le `deny ip any any` : elle ne sert à rien. Donne-lui un **numéro** inférieur :

```text
ip access-list extended INVITES-IN
 25 permit udp 192.168.50.64 0.0.0.63 host 192.168.50.34 eq 53
```

</details>
