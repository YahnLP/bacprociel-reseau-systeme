<details markdown="1"><summary>Aide</summary>

Oui : HTTP est **en clair**. En **HTTPS**, le contenu serait **chiffré** (port 443) : on ne verrait que l'adresse du serveur et des octets illisibles. C'est pour cela que les mots de passe ne doivent jamais passer en HTTP.

## 🔍 Dépannage

| Symptôme | Cause probable | Que faire |
|---|---|---|
| Pas de DHCP dans la capture | La capture a démarré après | **Efface**, puis refais `ipconfig /release` et `/renew` |
| Trop de trames | Pas de filtre | `dhcp`, `dns`, `tcp` ou `http` |
| `curl` ne répond pas | Pas d'adresse IP | `ipconfig /renew`, vérifier le câble |
| Pas de trame DNS | Le nom est en cache | Utiliser un autre nom (ou recharger le fichier) |
