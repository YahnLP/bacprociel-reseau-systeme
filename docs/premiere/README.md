# 🌿 Première – Réseaux et systèmes (E31)

**Objectif de l'année :** **comprendre ce qui circule** sur un réseau et **configurer** des équipements administrables : switch, routeur, VLAN, serveurs Linux, DHCP, DNS, sécurité de base.

**Progression :** 🔍 les couches et les protocoles (on *regarde* les trames) → 🔀 switch, sous-réseaux, routeur → 🏷️ VLAN → 🖥️ serveurs (Linux, DHCP, DNS, web, partage) → 🛡️ sécurité de base → 🏗️ projet **A2**.

> [!NOTE]
> Chaque séance contient une **fiche séance**, un **cours** (avec des questions pour vérifier la compréhension), un **TP** guidé et, quand c'est utile, un **fichier pour le simulateur réseau** à ouvrir hors ligne.
