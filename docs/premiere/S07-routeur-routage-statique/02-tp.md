# 🛠️ TP – Relier deux agences avec deux routeurs

*Bac Pro CIEL – Première – E31 – S07 – binôme, on **échange les rôles** à chaque partie*

> [!NOTE]
> **Mission.** Une entreprise ouvre une **agence** reliée à son **siège** par une liaison entre deux routeurs neufs. Chaque site a son réseau et fonctionne seul, mais **rien ne passe de l'un à l'autre**. Ta mission : **configurer les deux routeurs** pour que `PC1` (agence) joigne le **serveur** du siège — et que le serveur lui réponde.
>
> **Temps prévu :** 3 h 30. **Prérequis :** [cours S07](01-cours.md) lu, [aide-mémoire](03-aide-memoire-routeur.md) sous la main.

## Partie B – Les interfaces de R1 (≈ 30 min)

```text
configure terminal
hostname R1
interface gi0/0
 ip address 192.168.10.1 255.255.255.0
 no shutdown
 exit
interface gi0/1
 ip address 10.0.0.1 255.255.255.252
 no shutdown
 exit
end
show ip interface brief
```

✅ **Point de contrôle :** les deux interfaces sont `up` / `up`, et `PC1` **joint `192.168.10.1`**.

❓ **Si tu oublies `no shutdown`, que lit-on dans `show ip interface brief` ?** ______________________

## 🔍 Dépannage

| Symptôme | Cause probable | Que faire |
|---|---|---|
| Interface `administratively down` | `no shutdown` oublié | `interface …` puis `no shutdown` |
| `PC1` ne joint pas la passerelle | Mauvaise IP/masque, mauvais câble | Comparer avec le tableau |
| « Impossible de joindre le réseau de destination » | Le routeur **n'a pas de route** | `ip route …` |
| « Délai d'attente dépassé » après la route | **Route de retour** absente, ou passerelle du serveur fausse | Vérifier `show ip route` de l'autre routeur |
| `ping 10.0.0.2` échoue | Masque du lien différent d'un côté | Mettre `255.255.255.252` des deux côtés |
