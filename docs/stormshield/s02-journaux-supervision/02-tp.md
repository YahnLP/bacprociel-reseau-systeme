# 🛠️ TP – Le ping qui ne passe pas

*Parcours Stormshield – module S02 – individuel*

> [!NOTE]
> **Mission.** L'administrateur réseau (`PC-ADMIN`) veut **pinger** le serveur de la DMZ pour le superviser, mais ça ne marche pas. Tu trouves **pourquoi** dans le journal, puis tu corriges **sans** ouvrir le ping à tout le monde.
>
> **Temps prévu :** 30 min. **Prérequis :** [cours S02](01-cours.md).

Ouvre le [simulateur](../../simulateur/simulateur-reseau.html), puis **Ouvre** [`s02-journaux.json`](tp/s02-journaux.json).

## Partie C – Corriger proprement (≈ 10 min)

Dans **Règles de filtrage**, ajoute une règle : **Autoriser**, zone `LAN` → `DMZ`, protocole `icmp`, source **`192.168.1.10/32`** (uniquement `PC-ADMIN`), commentaire « Ping de supervision ». Elle doit être placée **avant** la fin de la politique.

Teste : `PC-ADMIN` pinge le serveur ; `PC-STAGIAIRE`, non ; le site web reste accessible aux deux.
