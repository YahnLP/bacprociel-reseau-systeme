# 🛠️ TP – Donner accès à un télétravailleur

*Parcours Stormshield – module S10 – binôme*

> [!NOTE]
> **Mission.** Une employée travaille depuis chez elle et doit accéder au serveur de fichiers de l'entreprise. Tu prépares puis réalises un **VPN nomade**.
>
> **Temps prévu :** 1 h 30. **Prérequis :** [cours S10](01-cours.md), [S08](../s08-utilisateurs-authentification/02-tp.md).

## Partie B – Sur un SNS (EVA) (≈ 40 min)

> [!EXAMPLE] 🚀 Pour aller plus loin
> 1. **VPN → VPN SSL** : active le service, saisis l'adresse publique, le port, le **réseau attribué aux clients** et les **réseaux accessibles**.
> 2. **Utilisateurs** : autorise un utilisateur (ou un groupe) à utiliser le VPN SSL.
> 3. Ajoute la règle de filtrage prévue en partie A.
> 4. Depuis le poste client, **télécharge le client** depuis le portail du pare-feu, connecte-toi et teste l'accès à la ressource.
> 5. Observe **Notifications → Journaux → VPN**.

| Question | Réponse |
|---|---|
| Quelle adresse reçoit le client ? | |
| Le client joint-il la ressource autorisée ? Une autre ? | |

## Partie C – Sans Stormshield : OpenVPN sur VirtualBox (≈ 30 min)

> [!NOTE]
> Pour comprendre le principe (tunnel TLS, certificat, client) sans EVA : installe **OpenVPN** sur une VM Linux (paquet `openvpn`, et l'outil `easy-rsa` pour les certificats), puis connecte une seconde VM. Suis la documentation officielle d'OpenVPN ; **prends un instantané** avant de commencer (voir [parcours serveurs, module 0](../../serveurs/m0-virtualbox/01-cours.md)). Ce TP n'a **pas été testé** dans ce site : adapte-le avec ton enseignant.
