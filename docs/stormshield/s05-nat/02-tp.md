# 🛠️ TP – Sortir sur Internet et publier un site

*Parcours Stormshield – module S05 – individuel*

> [!NOTE]
> **Mission.** Le pare-feu est configuré et filtré, mais **sans aucun NAT**. Tu fais sortir le LAN sur Internet, puis tu publies le site web de la DMZ.
>
> **Temps prévu :** 45 min. **Prérequis :** [cours S05](01-cours.md), [S04](../s04-configuration-reseau/02-tp.md).

## Mise en place

Ouvre le [simulateur](../../simulateur/simulateur-reseau.html), puis **Ouvre** [`s05-nat.json`](tp/s05-nat.json).

| Élément | Adresse |
|---|---|
| `FW1` (OUT) | 203.0.113.2/29 |
| `SRVWEB` (DMZ) | 172.16.0.10 |
| `WWW` (Internet) | 198.51.100.80 |
| `CLIENT` (Internet) | 198.51.100.20 |

## Partie A – Constater (≈ 5 min)

🤔 **J'anticipe** (écris ta réponse *avant* de manipuler) : Avant de tester : les deux accès vont-ils fonctionner sans NAT ? Pourquoi (adresses privées / publiques) ? ______________

Depuis `PC-ADMIN`, ouvre `http://198.51.100.80`. Depuis `CLIENT`, ouvre `http://203.0.113.2`.

| Question | Réponse |
|---|---|
| Les deux tests passent-ils ? | |

## Partie B – Masquerade (≈ 15 min)

Onglet **NAT / redirections** : ajoute **`LAN` → `WAN`**. Reteste `PC-ADMIN` → `http://198.51.100.80`.

| Question | Réponse |
|---|---|
| Quelle adresse le serveur `WWW` voit-il comme source ? | |
| Que se passerait-il sans masquerade ? (adresses privées sur Internet) | |

## Partie C – Publier le site (≈ 15 min)

Dans **Redirections de ports** : `tcp`, port externe **80**, vers **172.16.0.10**, port **80**. Reteste depuis `CLIENT` : `http://203.0.113.2`.

| Question | Réponse |
|---|---|
| Quelle règle de filtrage autorise ce flux ? | |
| Que se passe-t-il si tu désactives cette règle ? (essaie, puis réactive-la) | |

## Partie D – Réfléchir (≈ 10 min)

| Question | Réponse |
|---|---|

## 🔧 Partie – Pannes à diagnostiquer (≈ 20 min)

Quand tout marche, fais provoquer par ton binôme **une panne à la fois**. Pour chacune, ne touche à rien avant d'avoir lu le journal :

| Panne provoquée | Test | Ce que tu dois lire dans le journal |
|---|---|---|
| supprimer le **masquerade** | `PC-ADMIN` → site d'Internet | `PASS`, mais pas de réponse |
| supprimer la **redirection** | `CLIENT` → `http://203.0.113.2` | `BLOCK … WAN→FW … connexion vers le pare-feu refusée` |
| **désactiver** la règle `WAN → DMZ` | `CLIENT` → `http://203.0.113.2` | `BLOCK … WAN→DMZ … politique par défaut` |

❓ **Pour chaque cas, explique ce que l'adresse de destination du journal t'apprend.** ______________________
