# 🛠️ TP – Une politique de filtrage propre

*Parcours Stormshield – module S06 – individuel*

> [!NOTE]
> **Mission.** La politique actuelle est **trop large** et **mal ordonnée** : le stagiaire accède à tout. Tu la corriges selon le moindre privilège.
>
> **Temps prévu :** 45 min. **Prérequis :** [cours S06](01-cours.md).

## Mise en place

Ouvre le [simulateur](../../simulateur/simulateur-reseau.html), puis **Ouvre** [`s06-filtrage.json`](tp/s06-filtrage.json).

Cahier des charges :

| Qui | Peut… |
|---|---|
| `PC-STAGIAIRE` (192.168.1.50) | **rien** vers Internet |
| `PC-ADMIN` et les autres | le **web** (80, 443) et le **DNS** (UDP 53) vers Internet |
| Tout le LAN | le **site web de la DMZ** (TCP 80) |
| Personne | de **ping** vers Internet |

## Partie A – Constater (≈ 10 min)

🤔 **J'anticipe** (écris ta réponse *avant* de manipuler) : Avant de lire les règles : dans quel ordre le pare-feu les applique-t-il, et qu'arrive-t-il à un flux qu'aucune règle n'autorise ? ______________

Depuis `PC-STAGIAIRE`, ouvre `http://198.51.100.80`. Depuis `PC-ADMIN`, ping `198.51.100.80`.

| Question | Réponse |
|---|---|
| Le stagiaire passe-t-il ? Alors qu'une règle le bloque : pourquoi ? | |
| Que montre le compteur **Hits** de chaque règle ? | |

## Partie B – Corriger (≈ 20 min)

Onglet **Règles de filtrage** :

1. **Supprime** (ou désactive) la règle trop large « LAN vers Internet, tout » ;
2. place la règle **« Stagiaire bloqué »** **en premier** ;
3. ajoute **LAN → WAN, `tcp`, ports `80,443`** ;
4. ajoute **LAN → WAN, `udp`, port `53`** ;
5. garde **LAN → DMZ, `tcp`, port `80`**.

Ordre final attendu : 1) stagiaire bloqué, 2) web, 3) DNS, 4) DMZ.

## Partie D – Pour réfléchir (≈ 5 min)

| Question | Réponse |
|---|---|
| Que se passe-t-il si tu remets la règle du stagiaire **en dessous** de la règle web ? | |

## 🔧 Partie – Pannes à diagnostiquer (≈ 15 min)

| Panne provoquée | Test | Ligne attendue dans le journal |
|---|---|---|
| déplacer la règle « stagiaire bloqué » **sous** la règle web | `PC-STAGIAIRE` → site d'Internet | `PASS … règle 1` (au lieu de `BLOCK`) |
| changer la zone source de la règle « Site de la DMZ » (LAN → WAN) | `PC-ADMIN` → site de la DMZ | `BLOCK … LAN→DMZ … politique par défaut` |
| **décocher** une règle utile | le test concerné | `BLOCK … politique par défaut` |

Pour chaque panne, remplis une ligne du **journal de dépannage** (symptôme, ligne du journal, cause, correction, vérification).
