# 🛠️ TP – Table MAC et VLAN

*Parcours CCNA – Domaine 2 – module 2-01 – individuel ou binôme*

> [!NOTE]
> **Mission.** Un switch neuf relie quatre postes dans le même réseau `192.168.20.0/24`. Tu vas d'abord **observer la table MAC**, puis **séparer** la Comptabilité (VLAN 10) de l'Atelier (VLAN 20).
>
> **Temps prévu :** 40 min. **Prérequis :** [cours 2-01](01-cours.md).

## Mise en place

Ouvre le [simulateur](../../simulateur/simulateur-reseau.html), puis **Ouvre** [`c201-vlan-mac.json`](tp/c201-vlan-mac.json).

| Poste | Adresse | Port |
|---|---|---|
| `PC1` | 192.168.20.10 | Fa0/1 |
| `PC2` | 192.168.20.11 | Fa0/2 |
| `PC3` | 192.168.20.12 | Fa0/3 |
| `PC4` | 192.168.20.13 | Fa0/4 |

---

## Partie A – Observer la table MAC (≈ 10 min)

1. Sur `SW1` : `enable`, puis `show mac address-table`. Des adresses sont déjà là : les postes ont envoyé des messages en démarrant.
2. Vide la table : `clear mac address-table dynamic`, puis `show mac address-table` : elle est vide.
3. Depuis `PC1` : `ping -c 2 192.168.20.11`.
4. Sur `SW1` : `show mac address-table` de nouveau.

4. `clear mac address-table dynamic` puis `show mac address-table`. Que constates-tu ?

---

## Partie B – Séparer les services (≈ 15 min)

```text
configure terminal
vlan 10
 name COMPTA
vlan 20
 name ATELIER
 exit
interface range fa0/1 - 2
 switchport mode access
 switchport access vlan 10
 exit
interface range fa0/3 - 4
 switchport mode access
 switchport access vlan 20
 end
show vlan brief
```

✅ **Point de contrôle :** `show vlan brief` affiche `Fa0/1, Fa0/2` dans le VLAN 10 et `Fa0/3, Fa0/4` dans le VLAN 20.
