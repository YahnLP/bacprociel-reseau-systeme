# 🛠️ TP – Routes statiques, route par défaut et route flottante

*Parcours CCNA – Domaine 3 – module 3-02 – binôme*

> [!NOTE]
> **Mission.** Trois routeurs sont en triangle, **interfaces configurées, aucune route**. Tu dois permettre à `PC1` de joindre `PC3`, ajouter une **route par défaut**, puis une **route de secours** qui prend le relais si le lien `R1 – R2` tombe.
>
> **Temps prévu :** 1 h. **Prérequis :** [cours 3-02](01-cours.md).

> [!NOTE]
> **Comment ce TP fonctionne.** Les **commandes et réglages sont donnés** quand on ne peut pas les deviner : ton travail est de les **comprendre** (que fait chaque ligne, pourquoi, comment je le vérifie). Écris tes réponses aux ❓ **avant** de tester. Le **bilan final** nourrit ton **passeport d'autonomie**.

## Partie B – Les routes sur le chemin principal (≈ 20 min)

Le chemin principal est `R1 → R2 → R3`.

| Routeur | Réseaux à ajouter |
|---|---|
| `R1` | `192.168.3.0/24` via `10.0.12.2` ; `10.0.23.0/30` via `10.0.12.2` |
| `R2` | `192.168.1.0/24` via `10.0.12.1` ; `192.168.3.0/24` via `10.0.23.2` ; `10.0.13.0/30` via `10.0.12.1` |
| `R3` | `192.168.1.0/24` via `10.0.13.1` ; `10.0.12.0/30` via `10.0.13.1` |

Exemple sur `R1` :

```text
enable
configure terminal
ip route 192.168.3.0 255.255.255.0 10.0.12.2
ip route 10.0.23.0 255.255.255.252 10.0.12.2
end
show ip route
```

✅ **Point de contrôle :** `PC1` joint `PC3` et `PC3` joint `PC1`.

> [!NOTE]
> Le retour de `R3` passe **directement** par `R1` (lien `10.0.13.0/30`) : le chemin de retour n'est pas le même que l'aller. Ce n'est pas une erreur.

## Partie C – Route par défaut et route flottante (≈ 15 min)

Sur `R1` :

```text
configure terminal
ip route 0.0.0.0 0.0.0.0 10.0.12.2
ip route 0.0.0.0 0.0.0.0 10.0.13.2 200
ip route 192.168.3.0 255.255.255.0 10.0.13.2 200
end
show ip route
```
