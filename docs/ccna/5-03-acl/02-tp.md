# 🛠️ TP – Limiter l'accès à un serveur interne

*Parcours CCNA – Domaine 5 – module 5-03 – binôme*

> [!NOTE]
> **Mission.** Un serveur interne héberge l'intranet. Règles voulues : **PC-COMPTA** ouvre le **site web** (HTTP) du serveur, et **rien d'autre** ; **PC-STAGIAIRE** ne doit **rien** joindre sur le serveur.
>
> **Temps prévu :** 45 min. **Prérequis :** [cours 5-03](01-cours.md).

> [!NOTE]
> **Comment ce TP fonctionne.** Les **commandes et réglages sont donnés** quand on ne peut pas les deviner : ton travail est de les **comprendre** (que fait chaque ligne, pourquoi, comment je le vérifie). Écris tes réponses aux ❓ **avant** de tester. Le **bilan final** nourrit ton **passeport d'autonomie**.

## Partie B – Écrire l'ACL (≈ 15 min)

Sur `R1`, **dans cet ordre** :

```text
enable
configure terminal
ip access-list extended VERS-SERVEUR
 deny ip host 192.168.10.12 any
 permit tcp host 192.168.10.11 host 192.168.20.10 eq 80
 deny ip any any
 exit
interface gi0/0
 ip access-group VERS-SERVEUR in
 end
show access-lists
```
