# 🛠️ TP – Sécuriser l'accès distant d'un switch

*Parcours CCNA – Domaine 4 – module 4-05 – individuel*

> [!NOTE]
> **Mission.** Un switch est administré depuis le poste `PC-ADMIN`. Tu configures **SSH 2** avec un **compte local**, tu **limites les lignes vty à SSH**, puis tu te connectes.
>
> **Temps prévu :** 30 min. **Prérequis :** [cours 4-05](01-cours.md).

> [!NOTE]
> **Comment ce TP fonctionne.** Les **commandes sont données** quand on ne peut pas les deviner : ton travail est de les **comprendre** (que fait chaque ligne, pourquoi dans cet ordre, comment je le vérifie). Écris tes réponses aux 🤔 et ❓ **avant** de tester. Le **bilan final** nourrit ton **passeport d'autonomie**.

## Partie A – Configurer SSH (≈ 15 min)

🤔 **J'anticipe :** SSH chiffre la connexion. Que faut-il au switch pour pouvoir chiffrer (un nom ? une clé ?) et quelle commande va échouer si on oublie une étape ? ______________

```text
enable
configure terminal
hostname SW1
ip domain-name ciel.local
username admin secret Pa55w0rd!
crypto key generate rsa modulus 2048
ip ssh version 2
line vty 0 4
 login local
 transport input ssh
 end
write memory
```

## 🧊 Alternative avec Cisco Packet Tracer (TFTP)

> [!TIP]
> **TFTP n'est pas simulé** sur le site. Dans Packet Tracer :
>
> 1. Place un **serveur** (onglet **Services → TFTP**, service activé) relié au switch ou au routeur.
> 2. Sur l'équipement : `copy running-config tftp:` ; saisis l'adresse du serveur.
> 3. Vérifie le fichier dans **Services → TFTP** du serveur.
> 4. Inversement : `copy tftp: running-config` pour restaurer.
