# 🛠️ TP – Un serveur DHCP dans un autre réseau

*Parcours CCNA – Domaine 4 – module 4-02 – binôme*

> [!NOTE]
> **Mission.** Les postes sont dans le réseau `192.168.10.0/24` géré par `R1`. Le serveur DHCP est le routeur `R2`, **dans un autre réseau**. Tu crées le **pool** sur `R2` et le **relais** sur `R1`, puis tu vérifies que les postes reçoivent une adresse.
>
> **Temps prévu :** 40 min. **Prérequis :** [cours 4-02](01-cours.md).

> [!NOTE]
> **Comment ce TP fonctionne.** Les **commandes et réglages sont donnés** quand on ne peut pas les deviner : ton travail est de les **comprendre** (que fait chaque ligne, pourquoi, comment je le vérifie). Écris tes réponses aux ❓ **avant** de tester. Le **bilan final** nourrit ton **passeport d'autonomie**.

## Mise en place

Ouvre le [simulateur](../../simulateur/simulateur-reseau.html), puis **Ouvre** [`c402-dhcp-relais.json`](tp/c402-dhcp-relais.json).

| Élément | Adresse |
|---|---|
| `R1` gi0/0 (postes) | 192.168.10.1/24 |
| Lien `R1` gi0/1 ↔ `R2` gi0/1 | 10.0.0.0/30 (R1 = .1, R2 = .2) |
| `PC1`, `PC2` | clients DHCP, **sans adresse** au départ |

---

## Partie A – Constater (≈ 5 min)

Sur `PC1` : `ip -4 addr`. A-t-il une adresse `192.168.10.x` ? ______

---

## Partie B – Le pool sur R2 (≈ 10 min)

```text
enable
configure terminal
ip dhcp excluded-address 192.168.10.1 192.168.10.9
ip dhcp pool LAN10
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 8.8.8.8
 end
```

Les postes obtiennent-ils déjà une adresse ? ______ ❓ **Pourquoi pas ?** ______________________

---

## Partie C – Le relais sur R1 (≈ 10 min)

```text
enable
configure terminal
interface gi0/0
 ip helper-address 10.0.0.2
 end
```

Relance la demande sur un poste (désactive puis réactive l'interface ou le DHCP du poste, attends 10 s).

---

## Partie D – Vérifier (≈ 10 min)

| Commande | Résultat |
|---|---|
| `PC1` : `ip -4 addr` | |
| `PC2` : `ip -4 addr` | |
| `R2` : `show ip dhcp binding` | |

❓ **Pourquoi `192.168.10.1` à `.9` ne sont-elles jamais attribuées ?** ______________________

✅ **Point de contrôle final :** les deux postes ont **chacun** une adresse `192.168.10.x` différente.

---

## 🔧 Partie – Pannes à diagnostiquer (≈ 10 min)

| Panne à provoquer | Constat attendu | Commandes |
|---|---|---|
| `R1` : `interface gi0/0` puis `no ip helper-address 10.0.0.2` ; puis sur le poste `dhclient -r ens33` puis `dhclient ens33` | le poste n'a plus d'adresse | `ip a` sur le poste, `show ip dhcp binding` sur le serveur |

Rétablis le relais et vérifie que le poste obtient une adresse du pool.

❓ **Pourquoi le serveur ne reçoit-il pas la demande sans relais ?** ______________________
