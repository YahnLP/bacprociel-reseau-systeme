# 🛠️ TP – Deux switchs, deux VLAN, un routeur

*Parcours CCNA – Domaine 2 – module 2-02 – binôme*

> [!NOTE]
> **Mission.** Deux switchs hébergent chacun un poste de la **Comptabilité** (VLAN 10) et un poste de l'**Atelier** (VLAN 20). Tu dois créer les VLAN, relier les switchs par un **trunk** avec un **VLAN natif 99**, puis configurer un **routeur sur un bras** pour que les services communiquent.
>
> **Temps prévu :** 1 h. **Prérequis :** [cours 2-02](01-cours.md).

> [!NOTE]
> **Comment ce TP fonctionne.** Les **commandes sont données** quand on ne peut pas les deviner : ton travail est de les **comprendre** (que fait chaque ligne, pourquoi dans cet ordre, comment je le vérifie). Écris tes réponses aux 🤔 et ❓ **avant** de tester. Le **bilan final** nourrit ton **passeport d'autonomie**.

## Mise en place

Ouvre le [simulateur](../../simulateur/simulateur-reseau.html), puis **Ouvre** [`c202-trunk.json`](tp/c202-trunk.json). Les postes sont déjà adressés, switchs et routeur sont vierges.

| Poste | VLAN | Adresse | Switch / port |
|---|---|---|---|
| `PC10A` | 10 | 192.168.10.10/24 | SW1 Fa0/1 |
| `PC20A` | 20 | 192.168.20.10/24 | SW1 Fa0/2 |
| `PC10B` | 10 | 192.168.10.11/24 | SW2 Fa0/1 |
| `PC20B` | 20 | 192.168.20.11/24 | SW2 Fa0/2 |

Liens : `SW1 Fa0/24` ↔ `SW2 Fa0/24` ; `SW1 Fa0/23` ↔ `R1 gi0/0`.

## Partie B – Créer les VLAN sur **les deux** switchs (≈ 15 min)

```text
enable
configure terminal
vlan 10
 name COMPTA
vlan 20
 name ATELIER
vlan 99
 name NATIF
 exit
interface fa0/1
 switchport mode access
 switchport access vlan 10
 exit
interface fa0/2
 switchport mode access
 switchport access vlan 20
 end
show vlan brief
```

Sur les deux switchs. Puis refais le ping de la partie A.

✅ **Point de contrôle :** `PC10A` **ne joint plus** `PC10B` (les switchs ne sont pas encore reliés par un trunk).

---

## Partie C – Le trunk (≈ 15 min)

🤔 **J'anticipe :** un seul câble entre les deux switchs doit transporter deux VLAN. Comment le switch de l'autre côté sait-il à quel VLAN appartient chaque trame ? ______________

Sur `SW1` **et** `SW2` (port Fa0/24), et sur `SW1` pour Fa0/23 vers le routeur :

```text
interface fa0/24
 switchport mode trunk
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,99
```

`SW1` : applique les mêmes commandes sur `fa0/23`.

Vérifie : `show interfaces trunk` sur `SW1` et `SW2`.

## Partie D – Le routeur sur un bras (≈ 15 min)

```text
enable
configure terminal
interface gi0/0
 no shutdown
 exit
interface gi0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
 exit
interface gi0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
 exit
interface gi0/0.99
 encapsulation dot1Q 99 native
 ip address 192.168.99.1 255.255.255.0
 end
show ip interface brief
```

Teste : `PC10A` → `ping -c 2 192.168.20.11`.

✅ **Point de contrôle final :** les deux VLAN communiquent à travers le routeur.

## 🔧 Partie E – Pannes à diagnostiquer (≈ 20 min)

*En binôme : l'un provoque **une** panne (l'autre ne regarde pas), l'autre la trouve avec la méthode : poste → passerelle → trunk → routeur. On échange.*

| Panne à provoquer | Ce que le binôme doit constater | Commande qui le montre |
|---|---|---|
| `SW1` : `interface fa0/24` puis `switchport trunk allowed vlan 10,99` | VLAN 20 coupé entre les switchs, VLAN 10 intact | `show interfaces trunk` |
| `R1` : `interface gi0/0.20` puis `encapsulation dot1Q 30` | VLAN 20 sans passerelle, interface pourtant `up/up` | `show running-config interface gi0/0.20` |
| `R1` : `interface gi0/0` puis `shutdown` | plus aucun VLAN ne joint sa passerelle | `show ip interface brief` |
| `SW2` : `interface fa0/24` puis `switchport trunk native vlan 1` | **aucune coupure** : repérer l'incohérence | `show interfaces trunk` des **deux** switchs |
