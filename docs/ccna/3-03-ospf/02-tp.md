# 🛠️ TP – OSPF sur trois routeurs

*Parcours CCNA – Domaine 3 – module 3-03 – binôme*

> [!NOTE]
> **Mission.** Les trois routeurs du triangle ont leurs interfaces configurées mais **aucun routage**. Plutôt que d'écrire les routes à la main, tu actives **OSPF** (aire 0), tu fixes les **router-id**, tu protèges les LAN avec `passive-interface`, puis tu **testes une panne**.
>
> **Temps prévu :** 1 h. **Prérequis :** [cours 3-03](01-cours.md).

> [!NOTE]
> **Comment ce TP fonctionne.** Les **commandes et réglages sont donnés** quand on ne peut pas les deviner : ton travail est de les **comprendre** (que fait chaque ligne, pourquoi, comment je le vérifie). Écris tes réponses aux ❓ **avant** de tester. Le **bilan final** nourrit ton **passeport d'autonomie**.

## Mise en place

Ouvre le [simulateur](../../simulateur/simulateur-reseau.html), puis **Ouvre** [`c303-ospf.json`](tp/c303-ospf.json).

| Routeur | Router-id | Réseaux à annoncer |
|---|---|---|
| `R1` | 1.1.1.1 | `192.168.1.0/24`, `10.0.12.0/30`, `10.0.13.0/30` |
| `R2` | 2.2.2.2 | `10.0.12.0/30`, `10.0.23.0/30` |
| `R3` | 3.3.3.3 | `192.168.3.0/24`, `10.0.23.0/30`, `10.0.13.0/30` |

---

## Partie A – Activer OSPF (≈ 20 min)

Sur `R1` :

```text
enable
configure terminal
router ospf 1
 router-id 1.1.1.1
 network 192.168.1.0 0.0.0.255 area 0
 network 10.0.12.0 0.0.0.3 area 0
 network 10.0.13.0 0.0.0.3 area 0
 passive-interface gigabitEthernet 0/0
 end
```

Fais l'équivalent sur `R2` (sans passive-interface : il n'a pas de LAN) et sur `R3`.

> [!TIP]
> Les voisins mettent **jusqu'à 40 secondes** à se « voir » : attends avant de conclure à une erreur.

## Partie C – Panne et convergence (≈ 15 min)

1. `PC1` → `traceroute 192.168.3.10` : note le chemin.
2. Sur `R1`, `interface gi0/2` puis `shutdown` (coupe le lien direct vers R3).
3. Attends, puis `show ip route ospf` sur `R1`.
4. Refais le `traceroute`.

## 🔧 Partie D – Pannes à diagnostiquer (≈ 20 min)

*Une panne à la fois ; remets la configuration d'origine entre deux pannes. Après chaque modification, **attends environ une minute**.*

| Panne à provoquer | Constat attendu | Commande |
|---|---|---|
| `R2` : `router ospf 1` puis `passive-interface gi0/1` | un voisin de moins sur `R1`, routes passées par `R3` | `show ip ospf neighbor`, `show ip route ospf` |
| `R2` : remplacer `network 10.0.12.0 0.0.0.3 area 0` par `… area 1` | interface de `R2` en zone 1, 0 voisin | `show ip ospf interface brief` |
| `R2` : `interface gi0/1` puis `ip ospf hello-interval 5` | le voisin tombe malgré une configuration « correcte » | `show ip ospf interface gi0/1` (Hello 5 / 10) |
