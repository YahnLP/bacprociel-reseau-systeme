# 🛠️ TP – Un VPN IPsec entre deux sites

*Parcours CCNA – Domaine 5 – module 5-05 – binôme*

> [!NOTE]
> **Mission.** Deux sites (A et B) sont reliés par « Internet » (le routeur `ISP`), qui **ne route pas** les adresses privées. Tu configures un **VPN IPsec site à site** entre `R1` et `R2` pour que `PC1` joigne `PC2`.
>
> **Temps prévu :** 1 h. **Prérequis :** [cours 5-05](01-cours.md).

> [!NOTE]
> **Comment ce TP fonctionne.** Tu as un **but** et des **contraintes**. Les **commandes sont données** quand on ne peut pas les deviner : ton travail est de les **comprendre** (ce que fait chaque ligne, pourquoi dans cet ordre, comment tu le vérifies). Écris ta réponse aux 🤔 et ❓ **avant** de tester. Le **bilan final** nourrit ton **passeport d'autonomie**.

## Partie B – Configurer R1 (≈ 15 min)

🤔 **J'anticipe :** pour que deux routeurs montent un tunnel, qu'est-ce qui doit être **identique** des deux côtés, et qu'est-ce qui doit être **inversé** ? ______________

**But :** chiffrer le trafic entre `192.168.1.0/24` et `192.168.2.0/24` à travers Internet.

**Paramètres à respecter (phase 1 IKE, puis phase 2 IPsec) :**

| Élément | Valeur |
|---|---|
| Trafic à protéger (ACL 101) | `192.168.1.0/24` → `192.168.2.0/24` |
| Phase 1 | AES 256, SHA-256, clé pré-partagée, groupe DH 14 |
| Clé partagée | `Cle#VPN2027` |
| Pair (R2) | `198.51.100.6` |
| Phase 2 | `esp-aes 256` + `esp-sha256-hmac` |
| Application | *crypto map* sur `gi0/1` (interface WAN) |

<details markdown="1" open><summary>📌 Les commandes de R1 (à comprendre, pas à recopier)</summary>

```text
enable
configure terminal
access-list 101 permit ip 192.168.1.0 0.0.0.255 192.168.2.0 0.0.0.255
crypto isakmp policy 10
 encryption aes 256
 hash sha256
 authentication pre-share
 group 14
 exit
crypto isakmp key Cle#VPN2027 address 198.51.100.6
crypto ipsec transform-set TS esp-aes 256 esp-sha256-hmac
crypto map CMAP 10 ipsec-isakmp
 set peer 198.51.100.6
 set transform-set TS
 match address 101
 exit
interface gi0/1
 crypto map CMAP
 end
write memory
```

</details>

## Partie C – Configurer R2 (≈ 10 min)

**But :** configurer R2 comme **miroir** de R1. Écris d'abord, sans regarder, ce qui change côté R2 : ______________

<details markdown="1"><summary>💡 Aide – ce qu'il faut inverser (essaie d'abord)</summary>

| À inverser | Valeur sur R2 |
|---|---|
| ACL 101 | `permit ip 192.168.2.0 0.0.0.255 192.168.1.0 0.0.0.255` |
| `crypto isakmp key … address` | `198.51.100.1` |
| `set peer` | `198.51.100.1` |

Tout le reste (phases 1 et 2, clé) est **identique**.

</details>
