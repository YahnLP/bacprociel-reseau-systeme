# 🛠️ TP – Le PAT sur un routeur de bordure

*Parcours CCNA – Domaine 4 – module 4-01 – binôme*

> [!NOTE]
> **Mission.** Un routeur `R1` relie le LAN `192.168.10.0/24` au FAI (`203.0.113.0/29`). Les postes ont des adresses **privées** : tu dois leur donner accès au serveur web du FAI **grâce au PAT**, puis le **prouver** dans la table de traduction.

## Partie B – Configurer le PAT (≈ 15 min)

Sur `R1` :

```text
enable
configure terminal
access-list 1 permit 192.168.10.0 0.0.0.255
interface gi0/0
 ip nat inside
 exit
interface gi0/1
 ip nat outside
 exit
ip nat inside source list 1 interface gi0/1 overload
end
```

---
