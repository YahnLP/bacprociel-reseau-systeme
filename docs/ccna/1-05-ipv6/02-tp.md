# 🛠️ TP – Un réseau IPv6 à deux routeurs

*Parcours CCNA – Domaine 1 – module 1-05 – individuel ou binôme*

> [!NOTE]
> **Mission.** Deux routeurs, `R1` et `R2`, relient `PC1` et `PC2`. Tu dois **adresser** tout le monde en IPv6, **activer le routage**, ajouter des **routes statiques** et **prouver** que PC1 joint PC2.
>
> **Temps prévu :** 45 min. **Prérequis :** [cours 1-05](01-cours.md).

> [!NOTE]
> **Comment ce TP fonctionne.** Les **commandes sont données** quand on ne peut pas les deviner : ton travail est de les **comprendre** (que fait chaque ligne, pourquoi dans cet ordre, comment je le vérifie). Écris tes réponses aux 🤔 et ❓ **avant** de tester. Le **bilan final** nourrit ton **passeport d'autonomie**.

## Partie A – Configurer R1 (≈ 10 min)

🤔 **J'anticipe :** en IPv4 on donne une adresse par interface. Qu'est-ce qui sera différent en IPv6 sur une même interface (combien d'adresses, de quel type) ? ______________

```text
enable
configure terminal
ipv6 unicast-routing
interface gi0/0
 ipv6 address 2001:db8:acad:1::1/64
 no shutdown
 exit
interface gi0/1
 ipv6 address 2001:db8:acad:12::1/64
 no shutdown
 end
show ipv6 interface brief
```

## Partie C – Les routes statiques (≈ 10 min)

Sur `R1` : `ipv6 route 2001:db8:acad:2::/64 2001:db8:acad:12::2`
Sur `R2` : la route inverse vers `2001:db8:acad:1::/64`.

`show ipv6 route` : quelle lettre précède tes routes ? ______

---

## Partie D – Configurer les postes (≈ 10 min)

Sur `PC1` (terminal) :

```text
ip -6 addr add 2001:db8:acad:1::10/64 dev ens33
ip -6 route add default via 2001:db8:acad:1::1
```

Fais l'équivalent sur `PC2`. Puis :

```text
ping -6 -c 2 2001:db8:acad:2::10
```

✅ **Point de contrôle final :** PC1 joint PC2.
