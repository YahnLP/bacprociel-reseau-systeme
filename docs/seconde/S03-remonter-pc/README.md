> [!NOTE]
> **Question qui guide la séance :** *« Je démonte un PC, je le remonte : comment être sûr qu'il va redémarrer, et que faire quand il ne démarre pas ? »*

## 🎯 Objectifs

1. **Démonter et remonter** un PC en binôme avec une fiche pas à pas (RAM, SSD, alimentation, connecteurs de façade).
2. **Démarrer** le PC et **entrer dans le BIOS / UEFI**.
3. **Lire** les informations matériel, **régler** la date et l'heure, **changer** l'ordre de démarrage.
4. **Diagnostiquer** trois pannes simples : RAM mal enclenchée, alimentation oubliée, mauvais ordre de démarrage.

## 🧑‍🏫 Notes pour l'enseignant

<details markdown="1"><summary>Points d'attention</summary>

- Faire **photographier l'état initial** avant démontage pour pouvoir remonter.
- Le BIOS/UEFI diffère selon la marque : donner la **touche d'entrée** (Suppr, F2, F10, Échap) par modèle.
- **Pannes provoquées** : RAM à demi sortie, câble d'alimentation CPU débranché, ordre de démarrage modifié (mot de passe BIOS **non** défini).
- Rien d'irréversible : pas de réinitialisation avec mot de passe.

</details>
