![Les 8 points d'un poste prêt à l'emploi](images/poste-pret.svg)

| N° | Point à vérifier | Comment je vérifie | Fait | Vu par le binôme |
|---|---|---|:---:|:---:|
| 1 | Le poste porte un **nom clair** (`CIEL-PCxx`) | *Paramètres → Système → À propos de* | ☐ | ☐ |
| 2 | Compte **administrateur** et compte **standard** créés, mots de passe **notés** | *Paramètres → Comptes* | ☐ | ☐ |
| 3 | **Date, heure, langue, clavier** corrects | Barre des tâches, test de frappe (`é`, `à`, `@`) | ☐ | ☐ |
| 4 | Windows **à jour** | *Windows Update → « Vous êtes à jour »* | ☐ | ☐ |
| 5 | **Aucun triangle jaune** | Gestionnaire de périphériques | ☐ | ☐ |
| 6 | **Réseau OK** : une page web s'ouvre | Navigateur | ☐ | ☐ |
| 7 | **Antivirus actif** | *Sécurité Windows → Protection contre les virus* | ☐ | ☐ |
| 8 | **Logiciels demandés** installés et lancés | Les ouvrir depuis le compte standard | ☐ | ☐ |
