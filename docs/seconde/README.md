# 🌱 Seconde – Réseaux et systèmes (E31)

**Objectif de l'année :** devenir **autonome sur le matériel et le réseau de base**. L'élève n'a jamais fait d'informatique ni de réseau : on avance **une idée à la fois**, toujours en **manipulant d'abord**.

**Progression :** 🔧 le matériel (PC, systèmes, terminal) → 🔌 le câblage (réseau physique) → 🔢 les adresses (IP, DHCP, DNS) → 📶 le Wi-Fi → 🩺 le dépannage de niveau 1 → 🏗️ un petit projet complet (**A1**).

> [!NOTE]
> Chaque séance contient une **fiche séance**, un **cours** (avec des questions pour vérifier la compréhension), un **TP** guidé et, quand c'est utile, un **fichier pour le simulateur réseau** à ouvrir hors ligne.
