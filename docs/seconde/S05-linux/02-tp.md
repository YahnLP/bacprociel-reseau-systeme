## 💡 C'est quoi, une machine virtuelle ?

Une **machine virtuelle** (VM) est un **faux ordinateur** simulé par un logiciel (ici VirtualBox) à l'intérieur de ton vrai ordinateur. Elle a **son** disque (en réalité : un gros fichier), **sa** mémoire, **son** système.

**Avantage pour nous :** on peut tout casser, tout effacer, sans risque pour le vrai poste. En entreprise, on teste ainsi avant de déployer.

## Partie A – Créer la VM et installer Ubuntu (≈ 1 h 10)

### A1. Créer la machine virtuelle

1. Ouvrir **VirtualBox** → **Nouvelle**.
2. Nom : `Ubuntu-CIEL-xx` (xx = votre numéro). Dossier : celui indiqué par l'enseignant.
3. Fichier ISO : sélectionner l'ISO **Ubuntu 24.04** fournie.
4. **Matériel :** mémoire **4096 Mo**, processeurs **2**.
5. **Disque dur :** **25 Go** (créer un disque virtuel).
6. **Terminer**, puis **Démarrer**.

| Réglage choisi | Valeur | Équivalent dans un vrai PC |
|---|---|---|
| Mémoire | 4096 Mo | La **RAM** |
| Processeurs | 2 | Les **cœurs** du processeur |
| Disque | 25 Go | Le **SSD** |

✅ **Point de contrôle :** l'écran d'accueil d'Ubuntu apparaît.
❓ **Pourquoi** une VM est-elle sans risque pour le vrai poste ? ______________________

## Partie C – Installer et mettre à jour avec `apt` (≈ 40 min)

> [!NOTE]
> Vous allez ouvrir le **Terminal** pour la première fois (touches `Ctrl` + `Alt` + `T`). Le cours sur le terminal est en S06 : pour aujourd'hui, **on tape exactement ce qui est écrit** et on **comprend** ce que ça fait.

🤔 **Avant de taper :** `apt update` va-t-il installer des logiciels ou mettre à jour ceux qui existent ? Ton avis, même incertain : ______________

### C1. Mettre à jour le catalogue

```bash
sudo apt update
```

Il demande votre mot de passe (rien ne s'affiche quand on tape : c'est normal). Notez la dernière ligne affichée : ______________________

❓ **À quoi sert** `apt update` ? Ta prévision était-elle juste ? ______________________

### C2. Installer un logiciel

```bash
sudo apt install tree
```

Puis testez-le :

```bash
tree /home/eleve -L 1
```

Observez : que fait la commande `tree` ? ______________________

### C3. Mettre à jour le système

🤔 **Pourquoi** un technicien met-il à jour les systèmes **avant** de les confier à un client ? ______________


## 🔍 Dépannage

| Symptôme | Cause probable | Que faire |
|---|---|---|
| La VM ne démarre pas / erreur de virtualisation | Virtualisation désactivée dans le BIOS | Appeler l'enseignant |
| Écran trop petit | Pas de pilotes d'écran | *Périphériques → Insérer l'image CD des Additions invité* (selon l'enseignant) |
| `apt` : « impossible de verrouiller » | Une mise à jour automatique est en cours | Attendre 2 min, réessayer |
| `apt update` : erreur de connexion | Pas de réseau dans la VM | Vérifier le mode réseau (NAT) et le navigateur |
| `sudo` : « n'est pas dans le fichier sudoers » | Compte non administrateur | Appeler l'enseignant |
