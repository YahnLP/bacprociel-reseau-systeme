## 🧰 Préparation

1. Récupère le script de préparation :
   - **Linux :** [`creer-tresor.sh`](ressources/creer-tresor.sh)
   - **Windows :** [`creer-tresor.cmd`](ressources/creer-tresor.cmd)
2. Lance-le **une fois** :
   - Linux : `bash creer-tresor.sh`
   - Windows : double-clic (ou, dans `cmd` : `creer-tresor.cmd`)
3. Il crée un dossier `chasse-au-tresor` dans ton dossier personnel.
4. Ouvre un **terminal**, puis :

   | Linux | Windows |
   |---|---|
   | `cd ~/chasse-au-tresor` | `cd %USERPROFILE%\chasse-au-tresor` |
   | `ls` | `dir` |
   | `cat LISEZ-MOI.txt` | `type LISEZ-MOI.txt` |

> [!IMPORTANT]
> **Règles :** pas d'explorateur de fichiers, pas de souris pour naviguer. **Utilise `Tab`** pour compléter les noms. **Avant chaque commande, lis le prompt.**

## ❓ Questions de compréhension (à l'oral)

1. **Quelle est la différence** entre copier (`cp`) et déplacer (`mv`) ? Comment l'as-tu vu dans les listes ?
2. **Pourquoi** `cd ../../montagne/grotte` fonctionne-t-il depuis `riviere/pont` ? Que représente chaque `..` ?
3. **Écris** le chemin **absolu** de la grotte (indice : où est `chasse-au-tresor` ?). Pourquoi est-il plus long ?
4. **Pourquoi** est-il dangereux de faire `rm` sans regarder où l'on est ?
5. **À quoi sert** `ls -a` / `dir /a` ? Dans quel cas un fichier est-il caché ?

<details markdown="1">
<summary>Éléments de réponse</summary>

1. Copier laisse l'original ; déplacer le **retire** de l'endroit d'origine.
2. `..` = « dossier au-dessus » : depuis `pont`, le premier `..` mène à `riviere`, le second à `chasse-au-tresor`, puis on redescend dans `montagne/grotte`.
3. Linux : `/home/eleve/chasse-au-tresor/montagne/grotte` ; Windows : `C:\Users\eleve\chasse-au-tresor\montagne\grotte`. Plus long car il part de la racine.
4. Sans corbeille, on peut effacer **le mauvais fichier** ou **le mauvais dossier**, définitivement.
5. Elle affiche les fichiers **cachés** : sous Linux, ceux dont le nom commence par un point ; sous Windows, ceux qui ont l'attribut « caché ».

</details>
