*Bac Pro CIEL – Seconde – E31 – S02 – binôme*

> [!NOTE]
> **Mission.** Un client vous confie un PC de récupération « pour voir ce qu'il y a dedans ». Vous l'ouvrez, vous identifiez les pièces et vous produisez une **fiche d'identité photographique**.

**Binôme :** ____________ / ____________ **PC n° :** ____

## 🔰 Règles

- PC **débranché**, bracelet antistatique ou contact avec le boîtier.
- **On ne démonte rien** (on observe) sauf consigne de l'enseignant ; on **photographie**.
- Les vis vont dans le **bac**.

## A. Ouvrir et repérer (≈ 1 h 20)

1. **Débrancher**, retirer le panneau latéral.
2. Pour chaque pièce, **photographier** puis compléter :

| Pièce | Où est-elle ? (en haut, à gauche…) | Marque / modèle / valeur lue | Photo n° |
|---|---|---|---|
| Carte mère | | | |
| Processeur (sous le ventilateur) | | | |
| RAM | | Nombre de barrettes : ___ Capacité : ___ | |
| Stockage | | HDD ou SSD ? Capacité : ___ | |
| Alimentation | | Puissance (W) : ___ | |
| Ventilateur(s) | | Nombre : ___ | |
| Carte réseau | | Intégrée ou carte à part ? | |
| Pile | | Type : ___ | |

✅ **Point de contrôle :** vous retrouvez **les 8 pièces**.

❓ **Question :** combien de **câbles** partent de l'alimentation ? Vers quelles pièces ? ______________________

<details markdown="1"><summary>Aide</summary>

Le gros connecteur à 24 broches va à la **carte mère**, un connecteur à 4+4 broches au **processeur**, des connecteurs **SATA** aux disques. Suis les câbles du doigt (PC débranché !).

</details>

## B. Lire les étiquettes (≈ 50 min)

Les pièces portent des **étiquettes** qui disent leurs caractéristiques. Relève :

| Étiquette | Contenu lu | Ce que ça veut dire |
|---|---|---|
| Sur la RAM | (ex. DDR4, 8 Go, 3200 MHz) | |
| Sur le SSD/HDD | | |
| Sur l'alimentation | (ex. 500 W) | |
| Sur le processeur / ventilateur | | |

❓ **Pourquoi** la puissance de l'alimentation est-elle importante ? ______________________

<details markdown="1"><summary>Aide</summary>

Une alimentation **trop faible** ne peut pas alimenter un PC puissant (carte graphique, plusieurs disques) → le PC s'éteint ou ne démarre pas.

</details>

## C. Fiche « Anatomie d'un PC » (≈ 40 min)

Sur une feuille (ou sur ordinateur), **colle ou insère** votre **photo de l'intérieur** et **légende** au moins **6 pièces** avec :

- le **nom** ;
- le **rôle** (avec l'**analogie**) ;
- la valeur lue (capacité, modèle).

**Grille de contrôle :**

| Critère | ✅ |
|---|:---:|
| 6 pièces légendées correctement | ☐ |
| Rôle expliqué avec une analogie | ☐ |
| Valeurs lues (RAM, stockage) | ☐ |
| Photo nette | ☐ |

## 🏁 Vérification orale (2 min par élève)

1. **Montre-moi** la RAM. À quoi sert-elle ? Que se passe-t-il quand on éteint ?
2. **Montre-moi** le stockage. En quoi est-ce différent de la RAM ?
3. **Pourquoi** ce PC a-t-il un ventilateur ?
