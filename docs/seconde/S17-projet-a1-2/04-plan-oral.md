# 🗣️ Plan de l'oral – 5 minutes

*Projet A1 – prépare **des mots-clés**, pas des phrases à lire.*

| Temps | Partie | Je dis… | Mots-clés (à compléter) |
|---|---|---|---|
| 0:00 – 0:30 | **Le besoin** | Qui est le client, ce qu'il veut (B1 à B6) | |
| 0:30 – 1:30 | **Le schéma** | Je montre : box, switch, postes, imprimante, borne ; **les liens** | |
| 1:30 – 3:00 | **Mes choix** | Plage DHCP, adresse de l'imprimante (pourquoi ?), Wi-Fi invité (pourquoi séparé ?), droits (qui lit, qui modifie ?) | |
| 3:00 – 4:30 | **La démo** | **Un test en direct** : `ping` de l'imprimante, ou ouverture du site | |
| 4:30 – 5:00 | **Un problème rencontré** | Ce qui n'a pas marché, comment je l'ai trouvé (échelle du diagnostic), ce que j'ai appris | |

## ✅ Avant de passer

- [ ] Mon schéma est **lisible** de loin
- [ ] Ma démo est **préparée** (poste ouvert, commande prête)
- [ ] Je **connais** mes adresses sans regarder
- [ ] J'ai **chronométré** : moins de 5 minutes

## ❓ Questions possibles du jury

1. Pourquoi l'imprimante est-elle en **adresse fixe** ?
2. Que se passe-t-il si **deux postes** ont la même adresse ?
3. Pourquoi un **Wi-Fi invité** séparé ?
4. Un poste n'a plus Internet : **que testes-tu en premier** ?
5. Pourquoi **`atelier` ne peut pas supprimer** un fichier ?
