# 🛠️ TP – Installer vsftpd puis passer en SFTP

*Parcours serveurs – module 2 – individuel*

> [!NOTE]
> **Mission.** Tu installes un serveur FTP, tu **vois** le mot de passe passer en clair, puis tu refais le transfert en SFTP.
>
> **Temps prévu :** 1 h 15. **Prérequis :** [cours 2](01-cours.md), instantané propre de la VM, Wireshark sur ton PC.

## Partie A – Le serveur FTP (≈ 25 min)

```bash
sudo apt install -y vsftpd
sudo adduser eleve1
sudo nano /etc/vsftpd.conf
```

Règle `anonymous_enable=NO`, `local_enable=YES`, `write_enable=YES`, `chroot_local_user=YES` et `allow_writeable_chroot=YES` (pour ce TP seulement). Puis :

```bash
sudo systemctl restart vsftpd
sudo ss -tlnp | grep :21
```

Depuis ton PC : `ftp adresse-privee-hote` (ou FileZilla), connexion `eleve1`, puis `put` d'un fichier.

1. Lance **Wireshark** sur la carte réseau privée hôte de ton PC.
2. Filtre d'affichage : `ftp`.
3. Reconnecte-toi en FTP.

## Partie C – SFTP (≈ 20 min)

```bash
sudo apt install -y openssh-server
sftp eleve1@adresse-privee-hote
```

Fais un `put` et un `get`. Refais la capture avec le filtre `ssh` : plus rien n'est lisible.

Pour finir, désactive FTP :

```bash
sudo systemctl disable --now vsftpd
```
