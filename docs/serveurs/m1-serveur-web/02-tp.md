# 🛠️ TP – Installer Apache, Nginx puis LAMP

*Parcours serveurs – module 1 – individuel*

> [!NOTE]
> **Mission.** Sur ta VM `SRV-LINUX`, tu installes un serveur web, tu publies ta propre page, tu changes de serveur, puis tu montes la pile LAMP.
>
> **Temps prévu :** 1 h 30. **Prérequis :** [cours 1](01-cours.md) et un **instantané propre** de la VM.

## Partie A – Apache (≈ 25 min)

```bash
sudo apt update
sudo apt install -y apache2
systemctl status apache2
echo "<h1>Serveur de $(hostname)</h1>" | sudo tee /var/www/html/index.html
curl http://localhost
```

Depuis ton PC : `http://adresse-privee-hote/`.

## Partie B – Nginx à la place (≈ 20 min)

```bash
sudo systemctl disable --now apache2
sudo apt install -y nginx
systemctl status nginx
sudo ss -tlnp | grep :80
sudo nginx -t
```

## Partie C – LAMP (≈ 35 min)

```bash
sudo systemctl disable --now nginx
sudo systemctl enable --now apache2
sudo apt install -y mariadb-server php libapache2-mod-php php-mysql
echo "<?php phpinfo();" | sudo tee /var/www/html/info.php
```

Ouvre `http://adresse/info.php`. Puis crée une base :

```bash
sudo mysql
```

```sql
CREATE DATABASE test;
SHOW DATABASES;
EXIT;
```

Pour finir, **supprime `info.php`** : il révèle des informations sensibles.

```bash
sudo rm /var/www/html/info.php
```

## ✅ Points de contrôle
