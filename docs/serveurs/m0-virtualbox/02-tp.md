# 🛠️ TP – Préparer une VM serveur

*Parcours serveurs – module 0 – individuel*

> [!NOTE]
> **Mission.** Tu crées une VM Linux serveur, tu lui donnes deux cartes réseau, tu vérifies qu'elle accède à Internet et que ton PC la joint, puis tu prends un instantané.
>
> **Temps prévu :** 45 min. **Prérequis :** [cours 0](01-cours.md).

## Partie A – Créer la VM (≈ 20 min)

1. Dans VirtualBox : *Nouvelle*. Nom `SRV-LINUX`, type Linux (Debian 64 bits), **1 Go de RAM**, disque de **10 Go**.
2. *Paramètres → Système / Stockage* : monte l'ISO **Debian** (ou Ubuntu Server) fournie.
3. Installe en choisissant « serveur SSH » et « utilitaires usuels du système », **sans** environnement de bureau.

## Partie B – Les deux cartes réseau (≈ 10 min)

1. *Fichier → Outils → Gestionnaire de réseau* : crée un **réseau privé hôte** s'il n'existe pas.
2. VM éteinte, *Paramètres → Réseau* : **Carte 1** en NAT, **Carte 2** en réseau privé hôte.
3. Démarre la VM, puis vérifie :

```bash
ip a
ping -c 2 8.8.8.8
```

| Question | Réponse |
|---|---|
| Quelle adresse porte la carte privée hôte (souvent 192.168.56.x) ? | |
| Le ping vers 8.8.8.8 passe-t-il ? Par quelle carte ? | |

Si la carte 2 n'a pas d'adresse : `sudo dhclient` (ou `sudo ip link set <nom> up` puis relancer).

## Partie C – Joindre la VM et prendre un instantané (≈ 10 min)

Depuis ton PC : `ping adresse-privee-hote`, puis `ssh utilisateur@adresse-privee-hote`.

Dans VirtualBox : *Instantanés → Prendre* et nomme-le `propre-apres-installation`.

## ✅ Points de contrôle

- [ ] la VM sort sur Internet (NAT) ;
- [ ] mon PC joint la VM (réseau privé hôte, ping et SSH) ;
- [ ] j'ai créé l'instantané `propre-apres-installation` ;
- [ ] je sais le restaurer.

> [!TIP]
> **Dossier de preuves :** capture de `ip a` et de la liste des instantanés.
