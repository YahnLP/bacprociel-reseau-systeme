# 🛠️ TP – Créer un domaine et appliquer une GPO

*Parcours serveurs – module 4 – binôme*

> [!NOTE]
> **Mission.** Tu installes un contrôleur de domaine Windows Server, tu crées des utilisateurs, tu joins un poste client au domaine et tu appliques une GPO.
>
> **Temps prévu :** 3 h (peut se faire en deux séances). **Prérequis :** [cours 4](01-cours.md), [module 0](../m0-virtualbox/01-cours.md).

## Mise en place

| Élément | Réglages |
|---|---|
| **VM `SRV-AD`** (Windows Server, ISO d'évaluation fournie) | 2 Go de RAM minimum ; carte 1 NAT, carte 2 réseau privé hôte |
| **VM `CLIENT`** (Windows 10/11) | réseau privé hôte uniquement |

| Machine | Adresse (réseau privé hôte) | DNS |
|---|---|---|
| `SRV-AD` | 192.168.56.10/24 | 192.168.56.10 (lui-même) |
| `CLIENT` | 192.168.56.20/24 | 192.168.56.10 |

Prends un **instantané** de chaque VM avant de commencer.

> [!WARNING]
> Les noms de menus varient selon la version de Windows : cherche les rubriques indiquées en italique.

## Partie A – Le contrôleur de domaine (≈ 50 min)

1. Renomme le serveur `SRV-AD` et fixe son adresse IP.
2. *Gestionnaire de serveur → Ajouter des rôles* : coche **Services AD DS** (le DNS s'installe avec).
3. *Promouvoir ce serveur en contrôleur de domaine* : **nouvelle forêt**, domaine `entreprise.local`. Choisis un mot de passe de restauration.
4. Redémarre, puis connecte-toi avec le compte du domaine.

| Question | Réponse |
|---|---|
| Quel rôle fait aussi tourner le DNS ? | |

## Partie B – Les comptes (≈ 30 min)

Dans *Utilisateurs et ordinateurs Active Directory* :

1. crée une **OU** `Compta` ;
2. dans cette OU, crée deux utilisateurs (`alice`, `bob`) et un groupe `GrpCompta` qui les contient ;
3. crée aussi un utilisateur `chef` **en dehors** de l'OU `Compta`.

## Partie C – Joindre le client (≈ 30 min)

1. Sur `CLIENT`, vérifie l'IP et le DNS, puis `ping 192.168.56.10` et `nslookup entreprise.local`.
2. *Paramètres système → Domaine* : rejoins `entreprise.local` (compte administrateur du domaine). Redémarre.
3. Ouvre une session avec `alice`, puis `whoami`.

| Question | Réponse |
|---|---|
| Que renvoie `whoami` ? | |
| Que faire si la jonction échoue ? | |

## Partie D – Une GPO (≈ 40 min)

Sur `SRV-AD`, dans la *Gestion de stratégie de groupe* :

1. crée une GPO `FondEcran` **liée à l'OU `Compta`** ;
2. règle un fond d'écran imposé (ou un autre réglage visible, au choix de l'enseignant) ;
3. sur `CLIENT` : `gpupdate /force`, déconnecte-toi, reconnecte-toi en `alice`, puis `gpresult /r`.

| Question | Réponse |
|---|---|
| La GPO s'applique-t-elle à `alice` ? | |
| Et à `chef` ? Pourquoi ? | |

## ✅ Points de contrôle

- [ ] `alice` ouvre une session sur `CLIENT` avec son compte du domaine ;
- [ ] la GPO s'applique à `alice` mais pas à `chef` ;
- [ ] je sais expliquer : domaine, contrôleur de domaine, OU, GPO ;
- [ ] je sais pourquoi le DNS du client pointe vers le serveur AD.

> [!TIP]
> **Dossier de preuves :** capture de l'OU avec ses utilisateurs, de `whoami` sur le client et de `gpresult /r`.
